# NyaLife

Web で遊べる猫育成ゲームです。

## 機能
- 猫の状態管理（空腹・幸福・体力）
- ごはん / 遊ぶ / なでる / 清掃 / 休む
- レベルアップと EXP
- コインとおやつ、日々のイベント
- ローカルセーブとリセット
- シンプルな HTML/CSS/JavaScript で動作

## 使い方
ブラウザで `index.html` を開くだけで遊べます。

## 実装の特徴
- 依存ライブラリなし
- GitHub Pages でもそのまま配布可能
- 進行をローカルストレージに保存
