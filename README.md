# NyaLife

Web 上で遊べる簡単な猫育成ゲームです。  
猫の名前、レベル、満足度、空腹度、体力を管理して、毎日を幸せに過ごさせましょう。

## できること
- ごはんをあげる
- 遊んであげる
- なでる
- 眠らせる
- セーブ / リセット
- 自動で状態が減少する

## 使い方
ブラウザで `index.html` を開くと遊べます。  
ローカルストレージに自動保存されるので、ページを再読み込みしても状態が持続します。

## 実装方針
- 純粋な HTML/CSS/JavaScript で作成
- 依存ライブラリなし
- GitHub Pages でもそのまま配信しやすい
